# 🧪 Test & Verification Scripts

This folder contains verification and testing scripts used during development and testing phases.

---

## 📋 Scripts Overview

These are utility scripts created for:
- Credential verification
- Authentication testing
- Database validation
- System verification

---

## ⚠️ Note

These are development/testing scripts. In a production environment:
- Do NOT deploy these scripts to the server
- Delete or move to a separate admin folder
- Use proper admin interfaces for credential management
